PROBLEM STATEMENT
The API Authorization Blindspot in Modern Software
OWASP API1:2023 Slide 2 / 10
🚨
OWASP #1 CRITICAL THREAT Broken Object Level Authorization (BOLA / IDOR)
BOLA remains the most rampant and catastrophic flaw in cloud APIs. An authenticated attacker merely alters a numeric ID (/orders/101 → /orders/102) to view, modify, or delete another customer's confidential financial, identity, or medical records.
🛡️
CONVENTIONAL TOOLS FAIL DAST & SAST Are Blind to Multi-User Business Logic
Traditional scanners search for syntax anomalies like SQL injection and XSS payloads. They operate in a single-user sandbox and have zero contextual understanding of multi-tenant authorization boundaries, role hierarchies, or cross-account access rules.
⏱️
VELOCITY GAP Manual Penetration Testing Doesn't Scale in Agile CI/CD
Engineering teams deploy microservices dozens of times weekly. Manual security audits are expensive, quarterly, and too slow to catch day-to-day authorization regressions before code hits production environments.
🔥
SILENT EXPLOITATION Flaws Evade WAFs and Perimeter Defenses
Because BOLA requests use valid HTTP formats and legitimate credentials, target APIs respond with standard 200 OK payloads. Web Application Firewalls (WAFs) see normal traffic, resulting in undetected leaks and severe GDPR / HIPAA compliance penalties.

PROPOSED SOLUTION
Autonomous Differential API Security Testing
Autonomous Engine Slide 3 / 10
SentinelAPI automates end-to-end authorization security audits by ingesting OpenAPI contracts, discovering legitimate resource ownership across multiple authenticated personas, and executing differential response analysis to mathematically prove access violations.
1. SPEC-DRIVEN ATTACK SURFACE MAPPING
Contract Validation & Risk Prioritization
Ingests OpenAPI 3.x contracts from URLs or JSON/YAML. Automatically validates schemas, dereferences complex circular $ref pointers, and assigns preliminary risk rankings to state-changing operations and privileged routes.
2. MULTI-PERSONA GROUND-TRUTH MATRIX
Zero-Guesswork Ownership Discovery
Authenticates distinct test personas (userA, userB, admin) via JWT. Queries legitimate collection endpoints to learn owned resources without brute-force ID guessing, building a mathematical Allow/Deny expectation matrix.
3. DIFFERENTIAL RESPONSE ANALYSIS
Mathematical Distance & Field Divergence
Dispatches rate-limited cross-user attack probes. Analyzes baseline vs attack responses using weighted Jaccard similarity distance, status-code divergence, and undeclared sensitive field classification to detect breaches.
4. EMPIRICAL PROOF & REPRODUCIBLE POCS
Zero False Positives with cURL Evidence
Actively re-probes top findings against the live API to empirically prove reproducibility. Generates copy-pasteable, shell-safe cURL PoCs with masked $TOKEN placeholders for immediate engineering remediation.

Enterprise Safety Guardrails & Zero-Trust Design
Safety & Guardrails Slide 6 / 10
🛡️ ENFORCED SAFETY & EXECUTION BOUNDARIES
• Scope Guard (assert_in_scope)
Hardcoded validation against explicit ALLOWED_HOSTS. Probes to external domains or unauthorized IPs are terminated immediately with ScopeViolationError.
• Token-Bucket Rate Limiter (20 RPS)
Strictly throttles outbound probes to 20 requests/sec, preventing target denial-of-service, API degradation, or accidental lockout of customer services.
• Strict Request Budget Cap (1,000 req)
Hard cap prevents recursive endpoint traps, circular crawler loops, and runaway test case generation during automated audits.
• Defense-in-Depth Token Scrubbing
JWT tokens, passwords, and Authorization headers are permanently redacted before persistence or UI rendering. PoCs use $TOKEN placeholders.
• Shielded State Cleanup
Scanner-created test records are tracked and deleted in shielded finally blocks, leaving zero test artifacts behind on target APIs.
✨ EVIDENCE-ONLY AI & ARCHITECTURAL STACK
• Strict AI Separation of Concerns
The LLM (Groq, OpenRouter, Gemini) provides natural-language remediation and code fixes. The model NEVER participates in vulnerability detection or severity scoring.
• Pre-Flight Data Egress Assertion
assert_payload_safe() regex scans every outgoing prompt. Egress is immediately aborted if tokens, SSNs, credit cards, or internal IPs are detected.
• Deterministic Offline Fallbacks
If the LLM provider times out, returns malformed JSON, or exceeds rate limits, pre-compiled deterministic remediation templates activate seamlessly.
• FastAPI Async Backend & Atomic Storage
Python 3.11/3.14 with FastAPI async orchestrator, Pydantic v2 validation, in-memory atomic JSON store (scans.json), and real-time SSE streaming.
• Tactical Developer UI
React 19, Vite, Tailwind CSS with tactical tokens, WCAG AA contrast compliance, and responsive dark-mode developer dashboards.
